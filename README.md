# Heroes Against The End — V33

Nouvelle identité visuelle et nom de l’application. Icône créée pour le projet, utilisée pour installation PWA (192/512), écran d’accueil iOS et favicon. L’interface et les animations de boosters portent le nouveau nom. Les données de progression et les codes QR restent compatibles avec les versions précédentes : la clé de stockage existante n’a pas été modifiée.

Mise à jour : remplacer les fichiers du dépôt existant sans changer son adresse, puis recharger l’application. Pour actualiser l’icône d’une PWA déjà installée, il peut être nécessaire de la désinstaller puis de la réinstaller sans effacer les données du site.

V34 : image entière ou recadrage automatique (Éditeur > Image), disposition élargie sur PC, fond nocturne étoilé.


V35 : mana normal/hybride gratuit (0 PP), phyrexian 1 PP, {C} donne +1 PP de budget par exemplaire (max +3). Les coûts PP et le solde sont affichés explicitement.
